# 编程羊毛导航 · Coding Plan & 免费额度雷达

聚合市面上 AI 编程工具的 **Coding Plan、免费额度与限时优惠**，一键跳转领取。支持关键词查询更新、优惠力度统计图表与方案对比。

> 纯前端单页实现（HTML + CSS + JS），无需后端，双击 `index.html` 即可使用。

## 功能

- **羊毛总览**：72 条人工精选方案 + 自动抓取 150+ 条，覆盖主流 AI 编程工具
- **查询更新**：关键词实时过滤高亮，按平台 / 优惠类型 / 更新时间筛选
- **统计图表**：优惠力度分布、平台覆盖统计一目了然
- **方案对比**：勾选多个方案横向对比价格与额度
- **深浅色主题**：跟随切换，记忆偏好

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主页面（全部样式与逻辑内联，单文件即可运行） |
| `data.js` / `data-remote.json` / `data-remote.js` | 方案数据（本地内置 + 远程抓取格式） |
| `update_data.py` | 数据一键更新脚本（自动抓取最新方案） |
| `一键更新.bat` | Windows 双击更新数据 |

## 使用

1. 直接双击 `index.html` 在浏览器打开；
2. 想要最新数据：双击 `一键更新.bat`（需要 Python 3）。

## 数据更新

```bash
python update_data.py
```

脚本会重新抓取各工具官方页面的方案信息，合并进 `data.js`。
